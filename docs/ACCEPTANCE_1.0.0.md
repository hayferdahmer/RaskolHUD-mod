# RaskolHUD 1.0.0 — приёмка

## Цель

Зафиксировать обязательные автоматические и ручные проверки перед стабильным выпуском. Этот документ не означает, что ручная приёмка уже пройдена.

## Автоматические проверки

- [x] Протокольные round-trip тесты для базового состояния, характеристик и цели.
- [x] Проверки несовместимой версии, сигнатуры, обрезанного и чрезмерно большого пакета.
- [x] Проверка UTF-8 ограничений и отклонения некорректной UTF-8 последовательности.
- [x] Проверка ограничений уровней, таймеров эффектов, талантов и здоровья цели.
- [x] Unit-тесты чтения и нормализации локальной конфигурации.
- [x] CI запускает `:protocol:test`, `:client:test`, `:client:build`, `:bridge:build`.
- [x] Сборка и тесты выполняются на Java 25 / Gradle 9.5.1.

## Ручная проверка клиента

### Установка и запуск
- [ ] Чистый Fabric-профиль Minecraft 26.2 запускается с Loader 0.19.5 и Fabric API 0.161.0+26.2.
- [ ] Клиентский JAR RaskolHUD загружается без ошибок и конфликтов модов.
- [ ] Настройки открываются клавишей Right Shift; клавишу можно переназначить в Controls.
- [ ] Без серверного моста и без handshake мод не показывает устаревшие серверные данные.

### Основной HUD и боевые сигналы
- [ ] Класс, специализация, уровень, здоровье и ресурс совпадают с сервером.
- [ ] Броня и сытость совпадают с ванильным состоянием игрока.
- [ ] Эффекты, DoT и CC появляются, обновляют таймеры и исчезают после окончания.
- [ ] Кулдауны привязаны к правильным слотам хотбара.
- [ ] Классовые сигналы прицела соответствуют проверенным сценариям 0.5.1.

### Боевые характеристики
- [ ] Физическое и магическое сопротивление совпадают с серверными значениями.
- [ ] Уклонение, парирование, критический шанс ближнего боя и заклинаний совпадают с RaskolClasses.
- [ ] Доступные, потраченные и заработанные очки талантов отображаются корректно.
- [ ] Если серверные данные отсутствуют, панель не показывает фиктивные нули как достоверные значения.

### Рамка цели
- [ ] Для моба отображаются имя, тип и здоровье.
- [ ] Уровень моба появляется только при наличии EntityLevelProvider.
- [ ] Для игрока отображаются имя, класс, уровень и серверное здоровье.
- [ ] При потере цели, выходе за 32 блока, смерти цели или смене мира рамка исчезает.
- [ ] Панель цели не перекрывает фракцию/scoreboard в стандартном положении.

### Настройки и локализация
- [ ] Каждый из семи блоков можно включить и выключить независимо.
- [ ] Масштаб 75%, 100%, 125% и 150% проверен на нескольких разрешениях и GUI Scale.
- [ ] Все семь блоков перемещаются, прозрачность меняется от 20% до 100%.
- [ ] Позиции, прозрачность и переключатели сохраняются после перезапуска.
- [ ] Сброс отдельной позиции и полный сброс работают.
- [ ] Русский и английский языки корректно локализуют экран настроек.
- [ ] Старый конфиг автоматически дополняется новыми полями.
- [ ] Повреждённый конфиг восстанавливается к значениям по умолчанию после резервного копирования тестового файла.

### Соединение и fallback
- [ ] Подключение к Paper 26.2 с RaskolClasses и PlaceholderAPI выполняет handshake протокола v7.
- [ ] После disconnect HUD очищает серверные данные.
- [ ] После reconnect HUD появляется только после нового корректного снимка.
- [ ] Отключение заменяемых секций возвращает ванильные полосы здоровья, брони, голода и scoreboard.
- [ ] Игрок без Fabric-мода продолжает играть штатно; мост не требует мод от всех игроков.
- [ ] Другие игроки без handshake не получают HUD-снимки.

## Критерии выпуска

- [ ] Последний CI зелёный на HEAD PR.
- [ ] Ручной чек-лист заполнен владельцем проекта.
- [ ] Все найденные дефекты исправлены и повторно проверены.
- [ ] Подготовлена финальная версия 1.0.0 и артефакты клиента/моста.
- [ ] Владелец отдельно подтвердил публикацию.
- [ ] Только по отдельному решению владельца: снять Draft и перенести изменения в `main`.

До подтверждения владельца PR остаётся Draft, `main` не меняется, теги и GitHub Release не создаются.
