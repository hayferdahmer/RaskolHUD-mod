# Девятисегментный рендеринг готических рамок

## Назначение

Рамки HUD должны адаптироваться к ширине и высоте конкретного блока, не растягивая декоративные углы. Для этого `RaskolHudTextureRenderer` разбивает текстуру на девять областей:

- четыре угла рисуются без геометрического растяжения;
- верхняя и нижняя стороны растягиваются только по горизонтали;
- левая и правая стороны растягиваются только по вертикали;
- центральная область растягивается по обеим осям.

## Текущие точки применения

| Рамка | Исходный размер | Исходные отступы |
|---|---:|---:|
| Панель | 256 × 128 | 30 px по горизонтали, 24 px по вертикали |
| Слот | 96 × 96 | 18 px с каждой стороны |
| Портрет | 128 × 128 | 28 px с каждой стороны |
| Полоса | 512 × 48 | 24 px по горизонтали, 10 px по вертикали |

Размеры и отступы относятся к существующим текстурам в `assets/raskolhud/textures/gui`. Если исходная текстура будет заменена, её девятисегментные отступы необходимо перепроверить по фактической геометрии.

## Ограничения и дальнейшая проверка

- При целевом размере меньше суммы двух фиксированных краёв края пропорционально сжимаются, центральная область может стать нулевой.
- Девятисегментная схема не подходит для цельных орнаментов, где центральный самоцвет или узор должен оставаться строго в исходном масштабе.
- Перед релизом нужно проверить панели, слоты, портреты и полосы на нескольких GUI scale и разрешениях.
- Атлас PR #8 остаётся отдельным источником художественных ассетов; его отдельные очищенные вырезки не подменяются существующими текстурами автоматически.
